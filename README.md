Lantern Noodle Stall — a cozy night-market noodle cooking game. Orders arrive on the board with a timer; click the counter bins (or press 1–8) to build each dish on the plate, then serve with Space for coins plus a speed tip. A lost order costs one of three hearts, and every few dishes served the level rises: longer recipes, faster orders, a busier board. Warm flat colours drawn on canvas, tiny synthesized beeps and sizzles, no sound files, no network — just static files that play offline in a desktop browser.

## Run it

```sh
node main.ts
```
